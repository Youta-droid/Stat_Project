# Stat_Project

A student project for **StatProg2 (LMU Munich)** analysing the **World Happiness Report 2025** data — country-year life-evaluation scores and the factors behind them (GDP, social support, health, freedom, generosity, corruption) — to ask what explains happiness and what remains unexplained.

Built as a Quarto website.

## Group members

- Shohei Kobayashi
- Eya Fares
- Slaheddine Azzabi

## Dataset

World Happiness Report 2025, *Data for Figure 2.1* (`WHR25_Data_Figure_2.1v3.xlsx`): 1,969 country-year rows, 2011–2024. Underlying data from the Gallup World Poll. See the [dataset page](Stat/Quarto/data.qmd) for details.
